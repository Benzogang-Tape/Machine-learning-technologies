# Лабораторные работы по дисциплине «Технологии машинного обучения»

## ЛР1 — Разведочный анализ и визуализация данных
**Датасет:** California Housing (`sklearn`, 20 640 × 9, без пропусков) — `lab1/california_housing.csv`.

**Методы:** `describe`/`info`, гистограммы + KDE, сетка распределений, боксплоты на z-нормированных признаках, географический scatter (`Lat`/`Lon`, цвет = цена, размер = население), pairplot подвыборки, hexbin jointplot, тепловые карты корреляций Пирсона и Спирмана с маской верхнего треугольника.

**Результаты:** самая сильная связь с целью — `MedInc` (Пирсон ≈ 0.69); `AveRooms` ↔ `AveBedrms` мультиколлинеарны (≈ 0.85); расхождение Спирман/Пирсон у `AveRooms` указывает на нелинейность; высокие цены сконцентрированы на побережье.

## ЛР2 — Пропуски, кодирование категорий, масштабирование
**Датасет:** Titanic (`seaborn.load_dataset`, 891 × 15) — `lab2/titanic.csv`. Пропуски в `age` (~20 %), `deck` (~77 %), `embarked`.

**Методы:**
- *Пропуски:* heatmap + bar-chart, `dropna`, `fillna(median/mode)`, `SimpleImputer` (median / most_frequent / constant), `KNNImputer`.
- *Кодирование:* `LabelEncoder`, `OrdinalEncoder` с явным порядком классов, `OneHotEncoder` (с/без `drop='first'`), `pd.get_dummies`, frequency и target encoding.
- *Масштабирование:* `StandardScaler`, `MinMaxScaler`, `RobustScaler`, `MaxAbsScaler` со сравнением через гистограммы и боксплоты.
- *Финальный pipeline:* `ColumnTransformer` (числовые → KNNImputer + StandardScaler; низкокардинальные категории → SimpleImputer + OneHotEncoder; `deck` → constant-impute + OneHot).

**Результаты:** `KNNImputer` сохраняет форму распределения `age` лучше медианной импьютации; для `fare` с тяжёлым хвостом предпочтителен `RobustScaler`; `drop='first'` в OHE снимает мультиколлинеарность.

## ЛР3 — KNN, кросс-валидация, подбор гиперпараметров
**Датасет:** Wine (`sklearn`, 178 × 14, 3 класса) — `lab3/wine.csv`. Признаки сильно различаются по масштабу, что делает датасет наглядным для KNN.

**Методы:**
- `train_test_split` 75/25 со стратификацией.
- Базовый KNN (K = 5) без масштабирования vs со `StandardScaler` — accuracy/precision/recall/F1-macro + confusion matrix.
- Сетка гиперпараметров: `n_neighbors ∈ [1..30]` × `weights ∈ {uniform, distance}` × `p ∈ {1, 2}` (120 конфигураций).
- `GridSearchCV` и `RandomizedSearchCV` (`n_iter=25`) поверх `Pipeline(StandardScaler + KNN)`.
- Две CV-стратегии: `StratifiedKFold(5)` и `RepeatedStratifiedKFold(5×3)`.
- График accuracy(K) с mean ± std, сводная таблица сравнения базового / Grid / Random + три confusion matrix.

**Результаты:** масштабирование критично — даёт прыжок accuracy с ~0.7 до ~0.98; оптимальные параметры стабильны между двумя CV-стратегиями; Random ≈ Grid по качеству при заметно меньшем числе итераций.

## ЛР4 — Линейные модели, SVM и деревья решений
**Датасет:** Breast Cancer Wisconsin (`sklearn`, 569 × 31, бинарная классификация malignant/benign, без пропусков) — `lab4/breast_cancer.csv`.

**Методы:**
- Стратифицированный `train_test_split` 75/25, `StandardScaler` для линейных моделей и SVM.
- Логистическая регрессия (`LogisticRegression`), SVM с RBF-ядром (`SVC(probability=True)`), дерево решений (`DecisionTreeClassifier(max_depth=4)` — на неотмасштабированных данных).
- Две метрики качества: `Accuracy` и `ROC AUC` (дополнительно — F1, classification report).
- Сравнение: сводная таблица + barplot, три confusion matrix, ROC-кривые на одном графике.
- Важность признаков дерева — barplot по `feature_importances_`.
- Визуализация дерева через `plot_tree` + текстовый вывод правил через `export_text`.

**Результаты:** LogReg и SVM почти неотличимы (accuracy ≈ 0.97, ROC AUC ≈ 0.995); дерево с ограниченной глубиной слегка уступает по AUC из-за «ступенчатых» вероятностей, но выигрывает в интерпретируемости. Ключевые признаки в дереве — характеристики размера и формы опухоли (`worst radius`, `worst concave points`, `worst area`).

## ЛР5 — Ансамбли моделей: бэггинг, AdaBoost, градиентный бустинг
**Датасет:** Diabetes (`sklearn`, 442 × 11, регрессия — прогрессирование диабета через год, без пропусков, признаки уже нормированы) — `lab5/diabetes.csv`.

**Методы:**
- `train_test_split` 75/25 (масштабирование не требуется — деревьям не нужно, признаки уже центрированы).
- Бэггинг: `RandomForestRegressor(n_estimators=300)` и `ExtraTreesRegressor(n_estimators=300)`.
- `AdaBoostRegressor` поверх `DecisionTreeRegressor(max_depth=4)`, `n_estimators=300`, `learning_rate=0.05`.
- `GradientBoostingRegressor(n_estimators=300, learning_rate=0.05, max_depth=3)`.
- Baseline'ы для контекста: `LinearRegression` и одиночное `DecisionTreeRegressor`.
- Метрики: `MAE` и `R²` (плюс `RMSE`); сводная таблица + barplot, 4 диаграммы рассеяния `y_true` vs `y_pred`, сравнение важности признаков у RF / ET / GB на одном barplot.

**Результаты:** все ансамбли уверенно бьют одиночное дерево (R² с −0.07 → ~0.43–0.47); на этом датасете задача в значительной степени линейна, поэтому ансамбли лишь сопоставимы с `LinearRegression` (R² ≈ 0.45). Топ-признаки у всех трёх ансамблей одинаковы — `bmi` и `s5`, что согласуется с маргинальной корреляцией.

## ЛР6 — Условный экстремум: необходимые и достаточные условия (модуль оптимизации)
**Датасет:** не используется — задача чисто математическая (вариант 1.1 из методических указаний).

**Постановка:** `f(x₁, x₂) = (x₁ − 2)² + (x₂ − 3)² → extr` при ограничениях `g₁ = x₁² + x₂² − 5 = 0`, `g₂ = −x₁ ≤ 0`, `g₃ = −x₂ ≤ 0`. Геометрически — квадрат расстояния от точки `(2, 3)` до окружности радиуса `√5` в первом квадранте.

**Методы:**
- Обобщённая функция Лагранжа, перебор активных ограничений (4 случая), вывод стационарных точек через `sympy`.
- Необходимые условия первого порядка (КKТ): стационарность, допустимость, неотрицательность множителей, дополняющая нежёсткость.
- Достаточные условия второго порядка **двумя способами**: (1) знак `d²L` на касательных приращениях к активным ограничениям; (2) знак определителя окаймлённого гессиана.
- Численная проверка через `scipy.optimize.minimize(method='SLSQP')` с разных стартовых точек.
- Визуализация: линии уровня `f`, окружность ограничения, допустимая дуга, найденные экстремумы; профиль `f` вдоль дуги.

**Результаты:** локальный минимум — внутренняя точка `x* ≈ (1.240, 1.861)` с `f* ≈ 0.557` (линия уровня касается окружности); граничные точки `(0, √5)` и `(√5, 0)` дают `f ≈ 4.58` и `f ≈ 9.06` соответственно — точка C является глобальным максимумом по допустимой дуге. Оба способа проверки достаточных условий дают согласованный вывод; SLSQP подтверждает аналитику с любой стартовой точки.
